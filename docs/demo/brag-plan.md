# SILICONPILOT product film

The app compiles a documented dense/ReLU neural network into bit-exact ECP5 circuits and makes real synthesis/routing tradeoffs inspectable. The striking claim is a complete open-toolchain path with independently checked integer outputs, rather than a converter animation.

The visual hook is the project's restrained ivory hardware observatory, orange Pareto frontier and editable graph. Show actual app captures from the current measured corpus. User flow: inspect the model, change accuracy/resource budgets, select an independently verified candidate, open its generated HDL and waveform.

Tone: polished research instrument. Georgia display, system sans for interface copy and system monospace for measurements. Paper #f2f0e9, surface #fbfaf6, ink #202927, orange #d94a25, green #286b50. Use editorial geometry and thin circuit lines; no glows or generic digital wallpaper.
